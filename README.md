# I'm lilgossippack 👋

Hey, I'm lilgossippack. I spend most of my time writing Rust and C, usually building terminal tools or poking around Linux internals to see how things actually work under the hood. I'm drawn to the kind of work where shaving off a few microseconds feels like a real win — performance tuning, systems-level debugging, and lately a fair bit of WebAssembly. If it runs close to the hardware and compiles without a garbage collector, I'm probably interested.

---

#### What I'm up to

- 🔭 hacking on a lightweight CLI profiler for Wasm runtimes in Rust
- 💬 Ask me about Linux
- 📚 Currently reading whatever the docs link to
- 🤔 Thinking about terminal tools
